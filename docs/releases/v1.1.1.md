# LavaNotes 1.1.1

进行中更明显：整张便签亮起和纸色相同的呼吸光晕，进行中的勾选项整行发光。

## 改进

- **整张便签进行中**：点 ▷ 后，便签下半部亮起一圈缓缓呼吸的光晕，纸内从底边升起一层光，一眼就能看出哪张便签正在做。光晕所在的地方仍然可以点到后面的窗口。
- **颜色跟着纸色走**：奶油黄的便签发金黄的光，珊瑚粉发珊瑚红，薄荷绿发绿光，雾霭蓝发青光，丁香灰发紫光；“进行中”文字、标记和勾选方框也用同色系的深色。便签管理里的进行中标记同样跟着便签颜色。
- **进行中的勾选项整行发光**：右键方框标成进行中后，整行亮起一条从方框向右渐淡的光带，和方框里的圆点一起呼吸。
- **记开始时间，不再计时**：顶栏显示“进行中 · 10月9日 14:30 起”，不再按分钟计时，跨好几天的事也看得明白；便签管理卡片显示“进行中 · 10月9日起”。

## 说明

- 已安装旧版本的电脑会自动收到这个更新，也可以直接下载安装包覆盖安装，便签数据保留。
- 安装包未做代码签名。
