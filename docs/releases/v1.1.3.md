# LavaNotes 1.1.3

进行中的便签更醒目：光晕深呼吸，纸边有光在流动；修复便签刚收起或撕下又马上显示时消失。

## 改进

- **整张便签进行中**：与纸色相同的光晕包住整张便签、越往下越亮，呼吸得更深更快；纸边有两道光绕着便签流动，带着模糊的光尾；纸内底部的光随呼吸起伏，每隔几秒有一道高光斜着扫过纸面。
- **进行中的勾选项**：整行光带深呼吸，一道高光沿着这一行来回扫过，方框向外泛起波纹，开始或取消时文字不会移动。
- 便签四周的透明边距加宽了一点，用来放下更大的光晕；纸张位置不变，光晕处仍然可以点到后面的窗口。

## 修复

- 便签刚收起、撕下或废弃，又马上被显示（比如撕下后立刻“重新贴回”，或在便签管理里“收起”后马上“显示”）时，便签会显示中却看不到。现在会正常出现。

## 说明

- 已安装旧版本的电脑会自动收到这个更新，也可以直接下载安装包覆盖安装，便签数据保留。
- 安装包未做代码签名。
