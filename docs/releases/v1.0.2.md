# LavaNotes 1.0.2

新便签更像随手贴上去的纸，右上角改为“完成并撕下”。

## 改进

- 新建的便签重新左右交替倾斜，不再全部朝同一个方向歪；在一张便签上点 + 新建的那张会朝相反方向倾斜。已有便签的角度不变，可以在 ⋯ → 倾斜里调整。
- 新便签默认大小从 240×220 调大到 300×290。
- 便签右上角的图钉按钮换成 ✓“完成并撕下”，所有便签都可以用：便签被撕下收进归档，可以在便签管理里重新贴回。普通便签完成后会记作已完成的待办。
- “钉在桌面”移到 ⋯ → 窗口；钉在桌面的便签顶部会显示一个小图钉标记。
- 原来待办便签左下角的完成按钮去掉了，统一使用右上角的 ✓。

## 说明

- 已安装 1.0.0 / 1.0.1 的电脑会自动收到这个更新，也可以直接下载安装包覆盖安装，便签数据保留。
- 安装包未做代码签名。
