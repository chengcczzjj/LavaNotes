# LavaNotes 1.0.1

修复 Windows 上 1.0.0 便签无法使用的问题。

## 修复

- 便签窗口带着白色不透明底出现：便签改为各自单独创建窗口，页面加载后再设置一次透明背景，并在第一次显示时按 Windows 合成透明窗口的要求处理。
- 整张便签点不动、点击都落到了后面：改由程序自己跟踪光标位置判断光标是否在纸上，纸上可以正常点击、输入和拖动，纸外的透明边距点击仍会落到后面的窗口或桌面。

## 说明

- 每张便签现在各占一个进程，同时打开很多便签时内存占用会比 1.0.0 高一些。
- 已安装 1.0.0 的电脑会自动收到这个更新，也可以直接下载安装包覆盖安装，便签数据保留。
- 安装包未做代码签名。
