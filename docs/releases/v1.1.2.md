# LavaNotes 1.1.2

修复 AI 配置页重复出现的 API Key 卡片，翻译面板在配置好模型后自动恢复。

## 修复

- **AI 配置页的 API Key 卡片越来越多**：保存 Key 或切换服务商后，页面上会多出一张旧的 API Key 卡片（有的停在“正在识别…”），选好模型后也不消失。现在始终只有一张。
- **翻译面板留着旧提示**：没配置模型时点翻译，面板会提示去 AI 配置；配置好之后，面板以前会一直留着那条提示，现在会自动重新翻译。

## 改进

- 翻译出错时多了“重试”按钮。
- 模型漏译的段落不再一直显示成灰色、像还在翻译，而是提示“有 N 段没有译出，保留原文”，可以重试。

## 说明

- 已安装旧版本的电脑会自动收到这个更新，也可以直接下载安装包覆盖安装，便签数据保留。
- 安装包未做代码签名。
