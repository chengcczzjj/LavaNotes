# LavaNotes 1.1.0

翻译、便签统计和 AI 解读；正在做的事可以标成“进行中”；新的托盘菜单，便签上的鼠标指针不再闪。

## 新功能

- **进行中**：便签右上角 ✓ 左边新增 ▷，点一下标成进行中，顶栏显示“进行中 · 已用时间”，标记变成缓缓呼吸的圆点，顶栏下沿有一道淡淡的光流过；再点一下取消。撕下后保留开始时间，贴回时重新开始。
- **勾选清单的进行中**：方框有三种状态。单击方框和以前一样直接完成；右键方框标成进行中（琥珀色方框加呼吸圆点），再右键取消；已完成的项右键会回到进行中。每一项的添加、开始和勾选时间都会记下来。
- **翻译**：编辑工具栏的 T 菜单里（斜体、删除线也收在这里）。有选中的文字就翻译选中，否则按段落翻译整张便签；可以替换原文（列表、勾选、表格、图片原样保留）、插在下方或复制。
- **AI 配置**：便签管理新增“AI 配置”页，与 LavaTranslate 相同：ChatGPT Plus / Pro 会员登录，或填 Gemini、OpenAI、DeepSeek、通义千问、智谱、Kimi、豆包、Claude、OpenRouter、自定义兼容接口的 API Key（自动识别服务商，加密保存在本机）；也可以从 Codex、CC Switch 导入；模型列表附带价格。
- **便签统计**：按周 / 按月查看新写、撕下、废弃的便签和勾选清单的完成情况、用时；“进与出”柱状图、每张便签的生命线、一周节奏或每日动静、最久没勾的事项。“AI 解读”可以让模型归纳这段时间的主题、节奏和被搁置的便签。
- **废弃**：⋯ → 废弃，不打算做的便签被揉皱收起；内容保留，计入统计，可以在便签管理里筛选“已废弃”重新贴回。

## 改进

- **托盘菜单**：右键托盘图标弹出新的菜单，去掉了原来左侧的大块空白；带图标，显示桌面上的便签数和进行中的数量，“开机启动”改成开关。
- **鼠标指针不再闪烁**：多张便签重叠时，在前面便签的按钮上移动，指针不再被后面的便签改来改去；便签上的指针统一为箭头，正文区域是文本光标，只有胶带是手形。
- **便签管理**：打开先看到便签统计，左侧依次是便签统计 / 便签管理 / 设置 / AI 配置；便签按未完成 / 已撕下 / 已废弃 / 全部筛选，进行中的便签带标记。托盘菜单的“便签管理”改为“打开 LavaNotes”。

## 说明

- 便签内容只在你点“翻译”或“AI 解读”时发送给你在 AI 配置里选的模型服务；不配置模型时这两个功能不可用，其他功能不受影响。
- 已安装旧版本的电脑会自动收到这个更新，也可以直接下载安装包覆盖安装，便签数据保留。
- 安装包未做代码签名。
