# LavaNotes 1.0.0

LavaNotes 的第一个版本：从 LavaDesk（原灵月桌面）的桌面便利贴拆分出来的独立便签软件。

## 新功能

- 每张便签都是一个独立的透明窗口，保留倾斜纸张、纸胶带/图钉/自然贴、纸纹和撕下动画。
- 三种窗口层级：普通窗口、置顶、钉在桌面。钉在桌面的便签在显示桌面（Win+D）和最小化全部窗口（Win+M）后仍然留在桌面上。
- 右下角折角拖动调整大小，编辑时也可以；尺寸范围 160×130 到 900×900。
- 富文本、勾选清单、图片（插入/粘贴/拖入/缩放）、简单表格。
- 便签为主、待办可选；待办支持截止时间、分类、重要、到期系统通知、完成撕下与归档。
- 便签管理：搜索、待办分组、周复盘、已撕下归档、设置。
- 托盘常驻、开机启动、`lavanotes://` 唤起、GitHub Releases 自动更新。

## 说明

- 不导入 LavaDesk 旧版内置便利贴的数据。
- 安装包未做代码签名。
