# LavaNotes 1.0.3

更简单的便签：点 ✓ 就是完成，新便签错开摆放、倾斜更明显。

## 改进

- 新便签不再叠在同一个位置：从屏幕右上开始向左错开摆放，每张相隔约半张纸、上下交替，相邻两张只重叠一小部分；已经有便签的位置会跳过。从便签上点 +、按 Ctrl+N、托盘新建都一样，新便签出现在被点便签所在的屏幕上。
- 新便签的倾斜更明显，并且左右交替（1.8°～3.4°）。已有便签的位置和角度不变。
- 点右上角 ✓ 就是完成：便签撕下后进入便签管理的“已撕下”，可以重新贴回或删除。
- ⋯ 菜单只保留纸色、便签管理和删除；删除不再二次确认（便签上和便签管理里都是；“已撕下”页的一键清空仍会确认一次）。
- 纸张固定方式只保留纸胶带，原来用图钉或自然贴的便签也显示为纸胶带。

## 移除

- 待办功能：截止时间、分类、重要标记、到期提醒，以及便签管理里的“待办”和“周复盘”页面。已有便签里的待办信息不再使用，便签内容和已撕下的便签都保留。
- ⋯ 菜单里的固定方式、窗口层级、设为待办、文字、倾斜和“先收起”。新便签的窗口层级仍可在便签管理 → 设置里选择。

## 说明

- 已安装旧版本的电脑会自动收到这个更新，也可以直接下载安装包覆盖安装，便签数据保留。
- 安装包未做代码签名。
