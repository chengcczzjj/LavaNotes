## 1.1.0 的内容

- **翻译**：编辑工具栏把斜体、删除线收进 T 二级菜单，菜单下方是“翻译”；有选中译选中，否则按段落译整张便签，可替换（保留列表、勾选、表格、图片）、插在下方、复制。
- **AI 配置**：管理窗口新增“AI 配置”页，服务商目录、Key 识别、加密保存、ChatGPT 会员登录、Codex / CC Switch 导入、带价格的模型列表都与 LavaTranslate 一致（新增依赖 `openai`，主进程使用）。
- **废弃**：⋯ 菜单删除左边加“废弃”，便签揉皱收起、写入 `abandonedAt`，在便签管理里筛选“已废弃”可贴回或清空，计入统计。
- **勾选清单的时间线**：每个勾选项记录 id、添加时间、勾选时间（存在正文里），单独统计。
- **管理窗口结构**：导航改为 便签统计（打开时的第一页）/ 便签管理 / 设置 / AI 配置；“全部便签”改名“便签管理”，已撕下、已废弃不再单独成页，改为便签管理里的筛选（进行中 / 已撕下 / 已废弃 / 全部，带数量）。便签 ⋯ 里的“便签管理”直接打开便签管理页；托盘菜单的“便签管理”改为“打开 LavaNotes”。
- **便签统计页**：按周 / 按月；指标卡、进与出（12 个周期）、便签生命线（可按 AI 主题分组）、一周节奏 / 每日动静、勾选清单；“AI 解读”调用同一个模型归纳主题、节奏、被搁置的便签，结果缓存在 `ai-insights.json`。
- **进行中**：便签顶栏 ✓ 左边加 ▷，点击标成进行中（顶栏显示“进行中 · 已用时间”，标记换成呼吸的圆点和绕圈的弧，顶栏下沿一道淡光流过），再点取消；写入 `startedAt`，撕下保留、贴回清除。勾选清单的方框改为自绘的三种状态：单击完成（不变），右键标成进行中（琥珀色方框加呼吸圆点），已完成的右键回到进行中；勾选项新增 `startedAt`。便签管理的“进行中”筛选改名“未完成”，进行中的便签卡片带标记；统计页“最久没勾的”里进行中的项显示琥珀色方框；统计“进行中 / 期末进行中”改为“未完成 / 期末未完成”。
- **托盘菜单**：Windows 上右键托盘弹出 LavaNotes 自己画的菜单（纸卡样式，图标、便签数和进行中数量、开机启动开关），不再有原生菜单左侧的空白列；加载失败时退回原生菜单。macOS / Linux 仍用原生菜单。
- **鼠标指针闪烁**：便签穿透去掉 `forward`（Electron 在 Windows 上会把鼠标移动转发给被挡住的重叠便签，后面的便签不停设置自己的光标）；便签上统一光标（按钮、顶栏、边缘都是箭头，正文含内边距是文本光标，只有胶带是手形）。
- 验证（以上三项）：本地 `npm test` 通过（单元测试 57 个）；`npm run test:smoke` 在本机 Windows 上新增检查全部通过（▷ 标记与取消、勾选项右键进行中再勾选保留开始时间、托盘菜单在工作区内弹出 / 开机启动原地切换 / Esc 关闭），Windows 真实点击穿透检查在去掉 `forward` 后仍通过；只有已知的 3 项副屏窗口尺寸检查失败（见下）。截图检查过便签进行中、勾选三种状态、托盘菜单、管理窗口标记的观感。**未验证**：实机上指针是否不再闪（需要多张重叠便签，鼠标在按钮间移动）、托盘菜单在任务栏位于上/左/右时的位置、混合 DPI 多屏下托盘菜单的尺寸、深色模式下的托盘菜单。

npm.cmd run dist          # 本地打安装包到 dist/
