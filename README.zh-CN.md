## 功能

- **每张便签都是一个独立窗口**：透明异形，纸张带纸纹、阴影和纸胶带；新便签左右交替倾斜、错开摆放，不会叠在同一个位置；点哪张哪张到最前。
- **新便签的窗口层级**在便签管理 → 设置里选：
  - **普通窗口**：可以被其他软件盖住，和平常的窗口一样；
  - **置顶**：始终在最前面；
  - **钉在桌面**：待在桌面图标之上、所有窗口之下，只在桌面露出时看得到；**显示桌面（Win+D）和最小化全部窗口（Win+M）都不会收起它**。
- **右下角折角拖动调整大小**，编辑时也可以；拖顶部纸条、胶带或纸边移动。
- **富文本**：粗体、下划线在工具栏上；斜体、删除线和**翻译**收在工具栏的 T 菜单里；项目/编号列表；勾选清单（单击方框完成，右键方框标成进行中；每一项的添加、开始和勾选时间都会记下来，用于统计）。
- **翻译**：有选中的文字就翻译选中，否则按段落翻译整张便签；可以替换原文（列表、勾选、表格、图片原样保留）、插在下方或复制。用“AI 配置”里选的模型。
- **图片**：按钮插入、直接粘贴截图、从资源管理器拖进来；拖图片四角缩放。图片单独存成文件，便签再多也不卡。
- **简单表格**：插入 3×3，增删行列、切换表头、拖列宽。
- **进行中**：正在做的便签点右上角的 ▷，顶栏显示“进行中 · 已用时间”，标记换成缓缓呼吸的圆点，顶栏下沿有一道淡淡的光流过；再点一下取消。
- **完成并撕下**：点便签右上角的 ✓ 就是完成，便签被撕下，在便签管理里筛选“已撕下”可以找到并重新贴回。
- **废弃**：⋯ → 废弃，不打算做的便签被揉皱收起；内容保留（便签管理里筛选“已废弃”），可以重新贴回，也计入统计。
- **便签统计**：按周 / 按月查看新写、撕下、废弃的便签和勾选清单的完成情况、用时；“进与出”柱状图、每张便签的“生命线”、一周节奏或每日动静、最久没勾的事项。还可以让模型解读这段时间的便签：归纳主题、写和完成的节奏、被搁置的事。
- **AI 配置**：与 LavaTranslate 相同——用 ChatGPT Plus / Pro 会员登录，或填 Gemini、OpenAI、DeepSeek、通义千问、智谱、Kimi、豆包、Claude、OpenRouter、自定义兼容接口的 API Key（自动识别是哪家，加密保存在本机）；模型列表附带 models.dev 的价格。
- **管理窗口**：打开先看到便签统计；“便签管理”里搜索便签，按未完成 / 已撕下 / 已废弃 / 全部筛选（进行中的便签带标记），撕下和废弃的可以重新贴回或删除。
- **托盘常驻、开机启动、自动更新**（GitHub Releases）。Windows 上右键托盘图标弹出 LavaNotes 自己的菜单：显示便签数和进行中的数量，开机启动是开关。

## 下载

到 [Releases](https://github.com/chengcczzjj/LavaNotes/releases/latest) 下载 `LavaNotes-Setup-<版本>.exe`。支持 Windows 10 / 11 x64。安装包没有代码签名，首次运行时 SmartScreen 可能提示，选择“仍要运行”即可。

## 使用

| 操作 | 方法 |
| --- | --- |
| 新建便签 | 托盘双击、托盘菜单、便签左上角 +，或在便签里按 Ctrl+N |
| 移动 | 拖顶部纸条、纸胶带或纸张左右边缘 |
| 调整大小 | 拖右下角折角 |
| 标成进行中 / 取消 | 便签右上角的 ▷ |
| 完成并撕下 | 便签右上角的 ✓ |
| 勾选项标成进行中 | 右键方框（再右键取消） |
| 斜体、删除线、翻译 | 编辑时工具栏上的 T 菜单 |
| 换纸色、打开便签管理、废弃、删除 | ⋯ 菜单 |
| 打开链接 | 按住 Ctrl 点击 |
| 把桌面上的便签都调到最前 | 单击托盘图标，或管理窗口左下角“显示全部便签” |

其他程序可以用 `lavanotes://new`（新建）、`lavanotes://manager`（便签管理）、`lavanotes://open`（显示全部）唤起 LavaNotes。

## 数据

全部保存在本机 `%APPDATA%\LavaNotes`：

```
notes-index.json         便签位置、颜色、层级、撕下时间
notes-index.backup.json  上一次成功读取的索引
notes/<id>.json          每张便签的正文
assets/<sha256>.<ext>    图片（同一张图只存一份）
settings.json            设置
ai-settings.json         模型服务设置（API Key 加密保存）
ai-insights.json         保存的 AI 解读
model-prices.json        模型价格缓存（来自 models.dev）
```

便签内容只在你点“翻译”或“生成解读”时发送给你配置的模型服务。

写入都是“先写临时文件再改名”；索引损坏时会移到旁边并用备份恢复，不会覆盖。

## 开发

需要 Node.js 22。

```bash
npm install
npm run dev           # 开发运行
npm test              # 类型检查 + lint + 单元测试
npm run test:smoke    # 构建后用真实 Electron 窗口跑一遍主要流程（Linux 需 xvfb-run）
npm run dist          # 构建 Windows 安装包（在 Windows 上运行）
```

推送 `v*` 标签，或在 Actions 里手动运行 **Release Windows** 并填写要创建的标签，GitHub Actions 会在 Windows 上测试、构建并发布 Release。设计说明见 [docs/architecture.md](docs/architecture.md)。
